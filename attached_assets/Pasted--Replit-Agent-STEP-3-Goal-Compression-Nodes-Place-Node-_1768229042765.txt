# Replit Agent — STEP 3
## Goal: Compression Nodes + “Place Node on Graph” + Persisted Positions

---

## STEP 3 — What we’re building

### A) MOLT Tab: Compression Visuals
When user selects blocks and triggers Compress (Bundle/Merge),
render a single compressed node representing that group.

Rules:
- Pre-compress: show individual blocks as nodes (current behavior).
- Post-compress: replace selected block nodes with 1 node:
  kind = "compressed"
  label = "BUNDLE (3)" or "MERGE (3)" + short list of ids/titles
  payload includes:
    - groupId
    - mode: "bundle" | "merge"
    - blockIds: string[]
    - derivedSummary: string

Edge behavior:
- Maintain ordering edges:
  prev -> compressed -> next

### B) NEO Tab: Place Nodes on a simple grid
A graph background grid (light, simple).
User can:
- Tap/click a grid cell → sets “cursor”
- Tap/click “Place” button (or tap node palette item) to place selected NeoBlock node there
No drag/drop.
Optional: tap placed node → “Move” mode:
- tap new grid cell → node teleports there.

### C) Persist Layout Positions
Store node positions per tab:
- moltPositions
- neoPositions
- sleevePositions (optional)
Persist to localStorage keyed by project/repl id.

---

## HARD RULES
- Do NOT change compiler core or schemas.
- Compression visualization is UI-only.
- “Compress” behavior must reflect existing app state/actions (do not invent new compiler ops).
- No drag/drop; only click/tap placement.

---

## STEP 3 — Files to Create / Update

### 1) Create layout persistence helpers
Create: `src/lib/layoutStore.ts`
- loadLayout(): { molt: Record<id,Pos>, neo: ..., sleeve: ... }
- saveLayout(next)
- Use localStorage safely (guard SSR, try/catch)

Pos shape:
- { x: number, y: number } where x/y are grid coordinates (integers)

### 2) Extend graphTypes for position + compressed
Update: `src/lib/graphTypes.ts`
- Add optional `pos?: { x:number; y:number }`
- Add `kind` union includes: "block" | "compressed" | "neoblock" | "sleeve" | etc.
- GraphNode.payload remains any, but keep stable fields for compressed groups.

### 3) MOLT compression model (UI-side)
Create: `src/lib/moltCompression.ts`
Exports:
- buildMoltGraph({ blocks, compressedGroups, positions }) => GraphData

Where `compressedGroups` is derived from existing stack state:
- If your app already stores bundle/merge groups, read that.
- If not, implement minimal UI storage:
  - When “Compress” pressed, create a group record in state:
    { id, mode, blockIds }

Then build graph nodes:
- Replace contiguous sequences matching group.blockIds with one node.

### 4) Update MoltGraphView to use compression graph builder
Update: `components/graphs/MoltGraphView.tsx`
- Use buildMoltGraph()
- Render compressed node with distinct styling (badge “BUNDLE” / “MERGE”)
- Clicking compressed node shows BottomPanel details listing included blocks.

### 5) Add Grid + Placement mechanics
Create: `src/components/graphs/GridSurface.tsx`
- Renders a full-size div with CSS background grid
- Handles click/tap:
  - translates clientX/clientY into grid coords (x,y)
  - calls onPickCell({x,y})

### 6) Update NeoGraphView for placement
Update: `components/graphs/NeoGraphView.tsx`
- Determine “placeable items”:
  - from compile output runtime spec (neo blocks)
  - OR fallback: one node “NeoBlock Result” when compile exists
- Add lightweight “placement mode”:
  State in CenterWorkspace (preferred):
    - activePlacementNodeId (string | null)
    - placementMode: "idle" | "placing" | "moving"
- UX:
  - Tap a node in Neo list (or tap in graph) → sets activePlacementNodeId
  - Tap grid cell → position saved for that node
  - Tap node already placed → enable move; next tap cell relocates

### 7) Wire persistence in CenterWorkspace
Update: `components/CenterWorkspace.tsx`
- On mount: loadLayout() into state
- Pass positions down to views
- On placement: update layout state + saveLayout()

## Acceptance Criteria

MOLT tab:
- Compress creates a visible compressed node
- Node click shows inspector with included block list
- Graph order preserved with edges

NEO tab:
- Grid visible
- User can place neo node by tapping grid
- User can move a placed node via select + tap new cell
- Positions persist after refresh

Mobile:
- Same interactions work with taps
- No layout collapse
- Drawers still function
