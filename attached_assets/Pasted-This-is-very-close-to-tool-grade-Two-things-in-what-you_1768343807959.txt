What’s still missing / needs tightening
1) onRehydrateStorage should not mutate state directly
This line is the problem:
Copy code
Ts
state.tutorialStep = step;
state.hydrated = true;
In Zustand, direct mutation here often doesn’t notify subscribers reliably. You want a store action that uses set().
Fix pattern (safe, deterministic):
Add an action recomputeTutorialStep() that calls set({ tutorialStep: ... })
Add an action setHydrated(true)
Call those actions in onRehydrateStorage
Store patch:
Copy code
Ts
// in state
hydrated: false,
setHydrated: (v: boolean) => set({ hydrated: v }),

recomputeTutorialStep: () => {
  const s = get();
  set({
    tutorialStep: computeTutorialStep(
      s.blocks, s.neoBlocks, s.neoStacks, s.sleeve, s.runtimeSpec
    ),
  });
},
Persist hook patch:
Copy code
Ts
onRehydrateStorage: () => (state) => {
  state?.recomputeTutorialStep();
  state?.setHydrated(true);
},
2) isMoltComplete(blocks) should use the spine, not all blocks
Right now, if someone has only 6 roles but duplicates a role, hasRole() can still fail correctly — but the “complete” gate should be defined as “spine complete,” not “anywhere in the pile complete.”
Make this the canonical rule:
Copy code
Ts
export function isMoltComplete(blocks: Block[]): boolean {
  const spine = getSpineBlocks(blocks);
  return MOLT_ORDER.every(r => spine.some(b => b.role === r));
}
That keeps extras from ever affecting completeness.
3) nextAllowedRole() returning "BLUEPRINT" when complete is semantically wrong
It’s not fatal if your UI disables “Add Next MOLT Block” once complete, but returning a “real role” invites accidental extra blueprint creation.
Safer API:
Copy code
Ts
export function nextAllowedRole(blocks: Block[]): MoltRole | null {
  for (const role of MOLT_ORDER) {
    if (!hasRole(getSpineBlocks(blocks), role)) return role;
  }
  return null; // complete
}
Then in UI: disable when nextAllowedRole(...) === null.
4) Tutorial step “extras unlocked” check should use extras count, not blocks.length > 7
Right now you do:
Copy code
Ts
blocks.length > 7 ? "EXTRA_BLOCKS_UNLOCKED" : "NEOBLOCK_CREATED";
Better:
Copy code
Ts
const extrasCount = blocks.length - getSpineBlocks(blocks).length;
return extrasCount > 0 ? "EXTRA_BLOCKS_UNLOCKED" : "NEOBLOCK_CREATED";
That’s accurate even if someone does weird ordering.
