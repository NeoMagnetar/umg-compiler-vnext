# UMG Studio — Block Tutorial v0

Universal Modular Generation (UMG) is a modular cognitive architecture built from composable Blocks that can be compressed into higher-order artifacts (NeoBlocks, NeoStacks, Sleeves).

This build ships **Block Tutorial mode only**, focused on guided construction, inspection, and persistence of UMG structures.
